### Overview

- **What it does**
  - `/inventorymonitor <player>` opens one screen that shows the **whole** inventory of the player, online or offline,
    and stays in sync with it in real time.
  - You can modify the inventory from the screen too: the changes are applied to the player (offline players' data is
    saved when the last viewer closes the screen).
- **Features**
  - One screen laid out like the vanilla inventory: armor, the player's model, offhand, main inventory and hotbar (the
    held slot is framed), the item on the cursor (view only), and the name and online / offline status of the player as
    the title. A tab on the top edge switches to the ender chest. The viewer's own inventory is beside it.
  - The model is a puppet only the viewer sees (a player entity sent to the viewer alone, under the viewer's feet), so
    offline players have one too and the target's emotes or movements are not shown. It wears the target's skin,
    armor and held items.
  - The screen is drawn by a bundled **resource pack** (JSON UI), see [Resource pack](#resource-pack).
  - Armor slots only accept the matching armor piece.
  - The command name, aliases and default permission are configurable.
  - Multi-language messages (`eng`, `kor`), editable in `plugins/InventoryMonitor/lang/<lang>/lang.ini`.

### Installation & Requirements

- **Server**
  - [axolotl-pm/PocketMine-MP](https://github.com/axolotl-pm/PocketMine-MP) `5.51` or higher (`plugin.yml` `api: [5.51.0]`).
  - PHP `8.4` or higher.
  - The [libcontainer](https://github.com/presentkim-pm/libcontainer) and
    [resourcepack-register](https://github.com/presentkim-pm/resourcepack-register) libraries are bundled into the
    plugin, nothing else is needed.
  - Players need a client that accepts the server resource pack (the plugin requires it, see below).
- **Installation**
  - Download `InventoryMonitor.phar` from [GitHub Releases][releases-url] and place it into your server's `plugins` directory.
  - Restart the server; the plugin will load automatically according to `plugin.yml`.
- **Old versions**
  - The version for PocketMine-MP API 3 (3.x) is kept on the
    [`legacy/pmmp-5.44`](https://github.com/presentkim-pm/inventorymonitor/tree/legacy/pmmp-5.44) branch.
- **Development**
  - `composer install` then `composer test` runs the PHPUnit tests.

### Resource pack

The plugin contains its resource pack (`resources/pack`, JSON UI). It is registered when the plugin enables: the server
sends it to every player that joins, and the plugin turns on the server's `force_resources` (players who refuse the pack
cannot join). Nothing has to be copied to `resource_packs/`. The pack version is the plugin version, and the pack only
changes the screen of this plugin: the screen is selected by the window title, which starts with `§b§w§i§m`, so every
other chest looks as usual (it works beside other packs that use the same technique).

| file                              | description                                                                    |
|-----------------------------------|--------------------------------------------------------------------------------|
| `manifest.json`                   | pack header and module (fixed UUIDs, the version follows the plugin)           |
| `ui/inventorymonitor.json`        | the screen: the target frame (tabs on its top edge, the name as title, armor, model, offhand, cursor, inventory / ender chest cells) and, in the classic UI, a second frame with the viewer's own inventory; generated by `tools/generate-ui.php` |
| `ui/chest_screen.json`            | inserts the screen into the classic UI and hides the whole vanilla chest window (the screen draws the viewer's inventory from the same collections) |
| `ui/pocket_containers.json`       | inserts the target panel into the pocket UI's container half and hides that half and its header; the player's own inventory half stays |
| `ui/_ui_defs.json`                | loads `ui/inventorymonitor.json`                                                |
| `texts/*.lang`                    | the captions (`en_US`, `ko_KR`)                                                 |

Layout changes: edit the constants of `tools/generate-ui.php` (or `tools/inventorymonitor.json.tpl`), run
`php tools/generate-ui.php`, commit the result.

#### Slot contract

The screen has 72 slots (`MonitorSlots`). The pack reads the slot number as the `collection_index` of `container_items`.

| slot    | content                | source                                      | mode                                          |
|---------|------------------------|---------------------------------------------|-----------------------------------------------|
| 0-8     | hotbar                 | player inventory 0-8                        | two-way                                       |
| 9-35    | main inventory         | player inventory 9-35                       | two-way                                       |
| 36-39   | helmet, chestplate, leggings, boots | armor inventory 0-3            | two-way, only the matching armor piece        |
| 40      | offhand                | off-hand inventory 0                        | two-way                                       |
| 41      | cursor                 | cursor inventory 0 (online players only)    | read-only                                     |
| 42      | name and status label  | data slot (`#hover_text` of the item name)  | locked                                        |
| 43      | model                  | data slot: the puppet's actor id in quotes (`"<id>"`), read as `#entity_id` by `live_horse_renderer` | locked |
| 44      | held hotbar slot       | data slot: `h<index>` (a bare number would be read as a number), frames that hotbar cell | locked |
| 45-71   | ender chest            | ender chest 0-26                            | two-way                                       |

The ranges are mirrored with libcontainer's `bind()`: what happens to the player shows up on the screen, and what a
viewer does on the screen is written to the player (or to the saved data of an offline player).

### Command

| command                         | aliases                                | description                                     |
|---------------------------------|----------------------------------------|-------------------------------------------------|
| `/inventorymonitor <player>`    | `invmonitor`, `iv`, `인벤토리모니터`        | Monitor the inventory of the player (in game only) |

An online player may be given by the beginning of the name; an offline player needs the full name and saved data.

### Permission

| permission             | default | description  |
|------------------------|---------|--------------|
| `inventorymonitor.cmd` | OP      | main command |

### Configuration

`plugins/InventoryMonitor/config.yml` is created on the first start (in the server language if it is `eng` or `kor`).

| key                  | default                                         | description                                         |
|----------------------|-------------------------------------------------|-----------------------------------------------------|
| `settings.language`  | server language / `eng`                         | language of the messages (`eng`, `kor`)             |
| `command.name`       | `inventorymonitor`                              | name of the main command                            |
| `command.aliases`    | `["invmonitor", "iv", "인벤토리모니터"]`        | aliases of the main command                         |
| `command.permission` | `"op"`                                          | default of `inventorymonitor.cmd` (`true`, `false`, `op`, `notop`) |
